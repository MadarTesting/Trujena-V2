# الدعم والتواصل (Merchant)

## Description
تمكين العميل من التواصل مع فريق الدعم الفني لتقديم استفسار أو طلب مساعدة بخصوص التطبيق أو الاشتراك.

## Actor
- العميل (صاحب المتجر)

## Pre-Conditions
- العميل مسجل الدخول إلى لوحة التحكم.
- لدى العميل اشتراك فعال.

## Main flow
1. يفتح العميل لوحة التحكم بعد تسجيل الدخول.
2. الدخول الى صفحة الدعم والتواصل.
3. يظهر نموذج تواصل يحتوي على الحقول التالية:
   - الاسم
   - رقم الهاتف
   - البريد الإلكتروني
   - نوع الطلب (استفسار / مشكلة)
   - محتوى الرسالة
4. يقوم العميل بملء البيانات المطلوبة والضغط على زر "إرسال".
5. يتم إرسال الطلب إلى لوحة تحكم الأدمن في قسم "طلبات الدعم الفني".

## Post Condition
يتم إرسال الرسالة إلى فريق الدعم وتسجيلها في النظام مع إشعار العميل باستلامها.

## Business Rules
- لا يمكن للعميل إرسال أكثر من طلب خلال 5 دقائق لتفادي التكرار.
- يتم تسجيل كل طلب دعم في قاعدة البيانات.
- تملأ حقول الاسم ورقم الهاتف والبريد بنفس بيانات التسجيل ويمكن للعميل تغييرها.
